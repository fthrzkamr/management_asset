✨ Tambah Routing Baru

  1. Klik tombol "Tambah Routing"
  2. Isi form dengan data routing:
    • Divisi: Pilih divisi target
    • Cabang: Isi cabang spesifik atau kosongkan untuk semua cabang
    • Status Awal: Status saat PPX disubmit (Leader/Kacab/Manager/Finance/HR/Direktur)
    • Approver Role: Role yang akan approve (hr/kacab/manag_finance/manag_operasional/ga)
    • Skip Leader: Ya = langsung ke approver, Tidak = melalui Leader
    • Status Routing: Aktif/Nonaktif
  3. Klik "Simpan"

✏️ Edit Routing

Klik icon pensil pada routing yang ingin diubah, edit data, lalu klik "Update"

🗑️ Hapus Routing

⚡ Quick Tips

💡 Prioritas Routing:
Routing dengan cabang spesifik lebih prioritas daripada global (NULL cabang).
Contoh: Finance AP Cibinong akan pakai routing "Finance AP + Cibinong", bukan "Finance AP + NULL"
⚠️ Fallback Logic:
Jika divisi tidak punya routing, sistem akan cek:
1. Cabang user → Kacab ada? → Status: Kacab, jika tidak → Status: Leader
2. Default → Status: Leader
✅ Best Practices:
• Test routing baru di development dulu
• Backup database sebelum modifikasi routing kritis
• Nonaktifkan routing lama dulu, monitor, baru hapus
• Dokumentasikan setiap perubahan routing
